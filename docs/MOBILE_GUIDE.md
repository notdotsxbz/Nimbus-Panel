# Mobile & Device Guide

NIMBUS is built for every device: phones (320 px and up), tablets, laptops and
desktops, with a PWA install on all platforms.

## Installing the PWA

| Device | Steps |
| --- | --- |
| Android (Chrome/Edge) | menu ⋮ → *Install app* |
| iPhone / iPad (Safari) | Share → *Add to Home Screen* |
| Windows / macOS (Chrome/Edge) | install icon in the address bar |
| Linux | same as desktop Chromium browsers |

The app runs standalone with a splash screen and adapts its layout per device.

## Mobile interface

- Compact navigation drawer; important destinations are thumb-reachable
- Full-width service cards with large, touch-friendly action buttons
- Connection details (IP, port, domain) have one-tap copy buttons
- Tables switch to card layouts — no horizontal scrolling
- Console: touch input, copy/paste, auto-scroll, log search, full-screen mode

## Tablet

Hybrid layout — collapsible sidebar, two-column dashboards, touch-friendly tables
and the service control toolbar.

## Desktop

Full sidebar, multi-column analytics, resource graphs, advanced tables, global
search with `Ctrl+K` / `Cmd+K`, keyboard shortcuts.

## Low Bandwidth Mode

Toggle in the sidebar. Reduces animation, disables decorative background effects,
slows graph refreshes and uses compact layouts. Essential controls (start/stop/
restart, console) always remain available.

## Accessibility

WCAG 2.2 AA practices: keyboard navigation, screen-reader labels, visible focus
indicators, strong contrast, reduced-motion support.
